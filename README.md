# Maven Fuzzy Factory: E-commerce Sales Performance and Customer Behaviour Analysis

## Project Overview

This project analyses Maven Fuzzy Factory's e-commerce sales performance and customer behaviour using website traffic, orders, products, order items and refund data.

The project was completed as part of the **AnalystLab Africa Experience Lab Internship Programme – Week 2, Data Analytics Track**.

The objective was to transform raw e-commerce data into meaningful business insights that can support better decision-making.

## Tools and Technologies

- **PostgreSQL:** Data cleaning, transformation, validation and SQL business analysis.
- **Microsoft Power BI:** Data modelling, DAX measures, data visualisation and interactive dashboard development.
- **Microsoft Word:** Project documentation and analytical reporting.

## Project Objectives

- Evaluate total orders, revenue and average order value.
- Identify the highest revenue-generating products.
- Analyse website traffic by marketing source and device type.
- Calculate the website session-to-order conversion rate.
- Examine refund volumes and values.
- Analyse monthly revenue trends.
- Develop an interactive dashboard and provide actionable business recommendations.

## Key Findings

| Metric | Result |
|---|---:|
| Total Orders | 32,313 |
| Total Revenue | $1,938,509.75 |
| Average Order Value | $59.99 |
| Website Sessions | 472,871 |
| Conversion Rate | 6.83% |
| Total Refunds | $85,338.69 |
| Refunded Order Items | 1,731 |

### Additional Insights

- The Original Mr. Fuzzy generated approximately 62.5% of total revenue.
- GSEARCH accounted for approximately 66.8% of website sessions.
- Desktop devices generated 69.2% of website traffic.
- December 2014 recorded the highest monthly revenue at $144,823.02.
- Product category analysis was limited by the absence of category information in the supplied dataset.

## Project Deliverables

1. Cleaned datasets and data transformation documentation.
2. SQL business analysis queries.
3. Interactive Power BI dashboard.
4. Analytical report.
5. Evidence-based business insights and recommendations.
